# Vortex Desk · 第四个数据大屏

## 视频分析

参考 mov8.mp4：1080 × 1350、30 fps、约 30.14 秒。画面使用黑色背景，彩色粒子龙卷占据中心与大部分背景，上部宽阔并超出画面，下部收束为发光尖端。螺旋丝状光带快速绕轴运动，青、蓝、紫、粉、橙、黄、绿沿高度与时间变化，底部有向外喷射的粒子和地面辉光。

| 区域 | 视觉与运动 |
| --- | --- |
| 中央 | 三维漏斗、密集短线、发光核心、粒子拖尾、底部喷射 |
| 左上 | 三行交易台标识，位于粒子场上方 |
| 左侧 | 六个操作员的状态与进度、彩色证据矩阵 |
| 左下 | 向上更新的 JSON 信号流 |
| 右上 | 仓位列表、决策速率折线和指标 |
| 中央浮层 | 风险检查、执行状态、上下文标识，带引线 |
| 右下 | Python 风格代码、高亮执行行、实时日志 |
| 底栏 | 操作员交接次数、三种资产的价格与迷你趋势图 |

视频强调持续的环流与颜色变化，面板并不挤占主画面，而是半透明地覆盖在粒子场两侧。实现以这套构图与动画关系为依据，文案与交易数据为演示内容。

## 工程接入

- 路由：`/#/screens/vortex-desk`，通过 Vue Router 按需加载。
- 源码：`src/dashboards/vortex-desk/`，分离视图、样式、状态模型与渲染引擎。
- 索引：新增“粒子可视化”分类，支持搜索、排序与预览。
- 延续 Vue 3、TypeScript、Vite，不增加第三方依赖。

粒子与丝线使用三维坐标生成，经过旋转和透视投影呈现空间深度。画面不使用视频背景、原视频截图或预渲染动图。指标和日志跟随统一演示时间，暂停、速度切换与重播保持同步。

主渲染使用原生 WebGL，包含 74,000 个粒子和 32,000 条切向丝线。静态种子上传一次，旋转、形变、透视和颜色在着色器中计算；加色叠加分离细丝、高亮和外围辉光。WebGL 不可用时回退为简化的 Canvas2D 三维投影，并支持图形上下文丢失后的恢复。

## 控制与边界

支持暂停、倍速、重播、重置视角和全屏；拖动、方向键可调整视角，滚轮及 `+` / `-` 缩放，`0` 重置。系统选择减少动态效果时默认暂停。离开路由会清理动画、事件监听器、尺寸观察器和图形资源。

1080 × 1350 竖屏优先对应参考构图，桌面横屏调整两侧面板间距；手机保留可访问的控件和面板。所有金融数值、订单、代码高亮及执行状态均为模拟，不连接账户、不下单、不执行展示的代码。

## 验证

检查范围包括 TypeScript、ESLint、生产构建、索引及前三个大屏回归、新大屏深链接、播放控制、三维视差、阶段推进、资源清理、横竖屏和手机布局。视觉复核使用实际运行截图与视频帧对照；性能结论仅适用于实际采样的设备和浏览器。

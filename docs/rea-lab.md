# Rea Lab · 逆向工程实验室

## 视频分析

参考 `mov7.mp4`，1440 × 1800，30 fps，约 20.1 秒。视频采用白色实验终端风格：顶部一行紧凑状态栏，中央双侧空间网络，底部六列实时监测面板。完整解析循环约 18 秒，片尾已经开始下一轮。

- 左侧 DISASM 使用棕金、珊瑚红和粉色，表示 64 个反汇编代理；右侧 DECOMP 使用青绿、蓝色和紫色，表示 16 个反编译代理。
- 两侧白色指令带向外弯曲，带上有密集刻度和短指令。面向中央的频谱线长短不断变化，外围细线从无序连接逐渐收束成对齐的线束。
- 中央 HANDOFF 方形标记、移动数据包与相位差指示连接两侧。镜头先查看全貌，再依次靠近反汇编侧与反编译侧，最后回到同步视图。
- 文案依次为 LOADING、LIFTING、DECOMPILING、SYNCING、RESOLVED；完成画面突出 1,536 lifted、1,207 decompiled 和 329 flagged。
- 底部六个面板是 disasm、decomp、handoff、code、mesh、sync，分别显示条形/热力统计、堆叠方块、交接队列、代码流、旋转点球和从错相到同相的波形。

## 实现与使用

第七屏路由为 `/#/screens/rea-lab`，从作品索引中的 Rea Lab 卡片进入。沿用 Vue 3、TypeScript 与 Vite，不新增运行时依赖。真实 XYZ 坐标经过透视投影形成双侧网络，状态与监测面板共享模拟时钟。

拖动或使用方向键调整视角，滚轮缩放。工具栏提供暂停、倍速、重播、重置视角、全屏与返回索引。减少动态效果偏好默认暂停；暂停时允许调整相机而不推进处理阶段。离开页面会取消绘制循环并移除事件和尺寸观察器。

18 秒循环经过五个阶段：0–2.6 秒加载，2.6–6 秒提升指令，6–9 秒反编译，9–14 秒同步，14–18 秒展示最终解析结果。循环完成后重新加载。界面中的二进制、代码、代理、队列和结果均为确定性演示数据，不执行真实反编译，不读取或上传本地二进制文件。

## 验证范围

浏览器回归覆盖深链接刷新、暂停/倍速/重播、五阶段与最终计数、下一轮重置、真实深度与暂停旋转视差、重复进入/退出时的单绘制循环清理、手机与竖屏布局、减少动态效果、处理中结果不超过输入数量，以及平滑重置途中再次缩放的连续性。视觉复核对照原片检查双弧指令带、暖冷色空间网络、镜头近景、同步阶段及底部六列面板。

# Jev Engine · 环形决策路由引擎

第八个数据大屏，根据 `mov6.mp4` 的视觉结构实现。原片为 720 × 900、30 fps、约 19.18 秒。访问 `/#/screens/jev-engine`；索引支持搜索「Jev」「环形」及「路由可视化」分类。

## 视频观察

- 黑色偏紫的工程监测终端采用细网格、等宽小字与浅色分隔线。顶部显示 JEV ENGINEERING 标题，以及三行持续变化的任务火焰图。
- 主体是具有明确中空区和厚度的彩色环体，而不是平面的放射图。大量细针从不同 XYZ 位置向外延伸，端点分布不规则；前后层粒子密度、明暗和投影尺寸不同。
- 青、蓝、紫、粉、金与黄绿沿环体分布。环体旋转时，局部白色高亮沿圆周扫过并拉长针束。事件标签以连线跟随亮起的节点，随后切换到新的事件。
- 右侧依次是三路负载曲线、48 档置信度直方图、CREATE / DECIDE / ACT 占比、循环状态及相机和延迟读数。
- 底部为横向令牌流量堆叠图，以及决策玫瑰图、演示成本和 Pareto 分布三个小面板。

## 实现

`model.ts` 定义快照与控制器契约。`engine.ts` 负责 2,600 根真实 XYZ 针束、透视投影、旋转、扫描、事件锚点以及相机交互。`JevEngine.vue` 用同一时间轴更新火焰图、指标和 SVG 统计面板，`style.css` 将终端布局限定在页面作用域内。

顶部火焰图以 60 / 132 / 144 px/s 的分层速度无缝左移，复用主渲染循环逐帧更新 transform；统计面板仍以较低频率刷新，避免每帧重算所有图表。暂停、倍速和重播共用模拟时钟。

暂停会冻结模拟时钟与监测图表，仍可手动检查空间视角。系统启用「减少动态效果」时默认暂停。路由退出时取消动画帧、断开尺寸观察器并移除事件监听器，避免后台继续渲染。实现复用 Vue、浏览器 Canvas 和 SVG，没有新增依赖。

## 操作

- 拖动画布或使用方向键旋转，滚轮或 `+` / `-` 缩放。
- 工具栏支持返回索引、暂停/播放、倍速、重播、重置视角和全屏。
- 桌面横屏与原片竖屏保留主体/侧栏/底部图表的层级；手机宽度下调整布局并保留控制入口。

## 数据范围与验证

这是参考视频风格的交互演示，路由负载、决策、置信度、成本及延迟均为确定性模拟值，不连接交易、推理或后台服务。标题中的账户名和模型标记属于参考画面的视觉文本，不代表任何实际账户接入或性能承诺。

浏览器回归覆盖深链接、目录注册、真实深度、相机视差、暂停和倍速、扫描推进、重播、路由资源清理与响应式布局。生产版本由现有 Vite 流程构建，沿用 Cloudflare Pages Git 部署。

# Signal Loom · 三维信号织机

## 视频分析

参考 `mov4.mp4`，720 × 900，30 fps，约 27 秒。画面为深蓝黑色推理终端，顶部约 15% 展示四个指标与业务案例，中央约 60% 为三维数据流，底部约 25% 为紧凑监测面板。

- 左侧三个输入头：青色 CHOICE、品红 SCORE、金色 NOUL。二进制输入流汇聚为高亮节点，再沿大量细丝分发。
- 中央丝束不是平面贝塞尔图：曲线处于不同深度，随镜头改变重叠次序。流动包有白色核心、彩色外光晕，周期性形成短促亮斑。
- 右侧是一面有厚度的数字墙，多层 0/1、点阵与三色数据包。侧视时看到透视压缩，正视时填满大部分主体区域。
- 镜头约 27 秒循环，在斜侧、正面、掠过矩阵、扇后及俯视等角度间巡游。十二个案例的 STATE → ASK → JEV → GATE → CODE 与高亮颜色同步。
- 底部：三路吞吐量、三线置信曲线、动作矩阵、chief.py 代码；第二行展示日志、LLM/JEV/code 分工、保护约束。

## 实现边界

新增独立 Vue 路由 `/#/screens/signal-loom`，沿用按需加载、生命周期清理和索引注册方式。三维几何与动画由独立引擎负责；Vue 面板消费降频快照，避免每个粒子驱动响应式更新。不新增运行依赖。使用 GPU 双尺度 Bloom：主图先绘制到帧缓冲，再以 1/6 分辨率合成近光晕与宽光晕，终端文字保持清晰。数字墙的泛光权重随相机投影变化，避免字符密集区域过曝。

所有业务指标、成本、决策和代码日志均为模拟数据；不会发起实际邮件、交易或其他外部动作。成本和延迟沿用视频展示值，并非项目服务的实测指标。

## 操作与验证

拖动旋转、滚轮缩放；画布聚焦后方向键旋转、`+` / `-` 缩放、`0` 重置。工具栏提供暂停、倍速、重播、重置、全屏和返回索引。减少动态效果偏好默认暂停。

验证覆盖深链接刷新、时间推进与暂停、XYZ 深度、相机交互、27 秒巡游和案例阶段、重复路由卸载、手机布局、WebGL 不可用、Shader 初始化失败和显卡上下文丢失时的回退。故障回退使用独立 Canvas 绘制层，保留原画布的交互与播放状态，退出时一并清理。预览图从实际渲染页面生成。

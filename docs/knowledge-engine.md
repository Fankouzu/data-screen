# Knowledge Engine · 三维知识图谱

## 视频分析

参考 `mov5.mp4`，720 × 900，30 fps，约 24.1 秒。整体为深绿黑色知识管理终端：顶部为标题和三角色进度条，中央约占屏幕三分之二，底部为四列、两行的八个监测面板。

- 多个文档簇组成有真实 XYZ 深度的图谱。珊瑚红与米白色球形节点具有明暗体积，细线在簇内密集连接、在簇间稀疏延伸；金色原始资料节点连接图谱。
- 文档名与片段编号随空间位置移动，选中文档的浮动检查卡显示声明、来源和确认日期。镜头推进和旋转时能看到不同深度的节点交错。
- 演示依次经过 READER 只读摄取、LIBRARIAN 写入十二个页面、ANSWER 保存回答、CHECKER 夜间检查。检查阶段以黄色标记“每日”与“每周”两份来源的冲突。
- 八个面板分别为 SHARED CHAT、WRITE QUEUE、PAGE INSPECTOR、GRAPH INDEX、RAW / IMMUTABLE、DOCUMENT DIFF、CITATION MATRIX、NIGHTLY CHECKER。写入进度、引用矩阵和检查计数跟随主时间线变化。

## 实现与使用

独立路由为 `/#/screens/knowledge-engine`，索引中登记为第六屏。沿用 Vue、TypeScript 和 Vite，不新增依赖。图谱引擎负责投影、动画时间线与渲染，Vue 负责终端面板和文档检查；预览图由实际渲染页面生成。

拖动或使用方向键旋转，滚轮缩放。点击球形节点、文档标签或写入队列，会用约 650 毫秒拉近并居中到所选节点，展开更大的详情卡；细分节点显示记录编号，来源节点显示原始资料路径。聚焦后视角锁定所选对象，可继续旋转与缩放，通过“返回全景”、重置视角或 `0`，以约 850 毫秒平滑拉远并恢复巡游；过渡中可再次选择节点，镜头从当前位置连续转向。暂停时拉近和返回过渡仍可运行，结束后停止绘制循环；减少动态效果时直接切换视角。工具栏提供暂停、倍速、重播、重置视角、全屏和返回索引。减少动态效果偏好默认暂停。窄屏将底部面板调整为两列，保持控件可访问。

所有图谱、文档、聊天、来源校验和冲突均为确定性模拟。不会读取真实知识库、写入文档或执行展示的命令。

后续配色调整参考系列前五屏：深海军蓝背景，青色、蓝色、紫色、珊瑚橙和薄荷绿区分十二个文档簇；节点、连线与标签共享配色，金色用于原始资料和冲突检查。底部八个面板按功能使用对应强调色，Canvas 回退也保留知识簇颜色。

## 验证范围

浏览器验证覆盖深链接刷新、播放控制、读取到冲突检查的完整时间线、文档选择、XYZ 深度与暂停视差、反复路由卸载、窄屏与减少动态效果、WebGL 缺失、Shader 初始化失败和显卡上下文丢失时的回退。视觉验证以原片同阶段截图为基准，分别检查图谱构图、球体明暗、标签和底部面板比例。

手动检查与演示流程分开：选择文档只改变检查卡和页面检查器，不会重定向写入目标或冲突来源；重置视角恢复自动跟随。节点从 2,788 增至 3,206，实际连线从 10,240 增至 11,483；阶段计数来自同一份图谱几何。

# Market Neural · 第三个数据大屏

## 视频分析

参考 mov3.mp4（1080 × 1350，约 28.35 秒）：整体是深色金融终端，上层为收益、关联信号、数据流检查器和盘口，中层为六路输入、三维神经球体和订单队列，下层为执行记录与成本分布。核心识别点是金白色三角网格、青色外层纤维、带发光端点的黄色触须，以及独立球体的融合与分裂。

| 视频时间 | 形态 |
| --- | --- |
| 0–4 秒 | 主球与两个卫星球分别旋转 |
| 4–7 秒 | 卫星球向核心融合 |
| 7–17 秒 | 统一球体呼吸、变形、旋转 |
| 17–21 秒 | 球体分裂并重新展开 |
| 21–28 秒 | 分布结构保持并进入下一周期 |

## 实现

`src/dashboards/market-neural/` 包含 Vue 视图、状态模型、Canvas 引擎和独立样式。复用现有 Vite、Vue Router、TypeScript 工程，不增加依赖。页面通过 `/#/screens/market-neural` 按需加载，并已加入索引、搜索、金融可视化分类与排序。

网格使用真实 XYZ 坐标：2,151 个节点、6,174 条网格边、280 根动态触须，包含主球、两个卫星球及各自的青色外壳。几何先旋转、变形、融合，再按相机角度和透视投影到 Canvas。深度影响线条亮度、节点大小及遮叠，拖动相机会产生不同深度的视差。融合保留所有顶点，改变其中心和半径，不使用视频背景或截图贴图。

拓扑仅在初始化时计算；每帧复用 typed arrays 和深度分桶，辉光图像预缓存，限制设备像素比。Vue 面板约 10Hz 更新，与动画时间共享同一快照。暂停停止 RAF，调整视角时仅按需绘制；离开路由清理 RAF、观察器、事件和缓存。

界面包含收益与盈亏图、五路关联曲线、数据流检查器、BTC 蜡烛图与买卖深度、六路输入小图、订单队列、成交记录、成交量分布、成本散点图和直方图。数据均为确定性模拟，不连接交易账户、行情 API 或订单执行服务。

## 交互与布局

- 自动 / 合并 / 分裂视图；暂停、倍速、重播、重置视角、全屏。
- 拖动或方向键旋转，滚轮或 `+` / `-` 缩放，`0` 重置。
- 1080 × 1350 竖屏对应视频构图；桌面横屏扩展信号连线与行情面板。
- 1600 × 1000 和 1080 × 1350 完整落在视口内；短桌面屏保留最小 860px 内容高度，手机纵向滚动。
- 系统启用减少动态效果时默认暂停，可以手动恢复播放。

## 验证范围

自动化覆盖索引及前两个大屏回归、新页面深链接、暂停与速度、四阶段完整周期、融合前后的 XYZ 坐标变化、暂停拖动视差、视角重置、反复进入退出的 RAF 清理、桌面横竖屏边界、手机布局和减少动态效果。使用本机 Chrome 检查渲染截图和浏览器异常；具体结果以 `npm run check` 及 GitHub Actions 为准。

相似性以构图、几何和动效为主；视频中的专有文案与金融数值采用演示内容。性能取决于设备、浏览器和窗口尺寸，帧率指标不代表交易系统性能。

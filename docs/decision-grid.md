# Decision Grid：第二段视频的分析与实现

参考视频为 `mov2.mp4`，1080 × 1350，60 fps，时长约 27 秒。工程不包含原视频文件，也不使用视频或截图作为动态场景背景。

## 画面与运动

- 顶部约 16%：窄标题栏、四项指标、当前案例与 STATE / ASK / JEV / GATE / CODE 阶段。
- 中部约 60%：多个深度上的卡片墙，白亮纵向神经束、细小跨墙连线、游走光点；当前案例以黄、青、珊瑚、蓝或紫色点亮。
- 底部约 22%：置信度曲线、12 案例、示例代码、并行问题、日志、执行分工与阈值面板。
- 原片在远景与近景之间快速推进、停留，然后切换案例。约 12 秒的线索决策呈黄色路径；后段支持工单以低于 0.85 的置信度转向人工复核。

## 实现方式

`model.ts` 定义 12 个演示案例与控制器接口；`engine.ts` 生成 600 张 XYZ 卡片和 15 组数据墙，以透视投影绘制到 Canvas。前后景缩放、旋转视差、墙体发光、连接流与镜头运动均实时计算。卡片标签使用可复用纹理，远处卡片简化绘制；设备像素比上限为 1.75。

默认每个案例持续 6 秒，依次经过五个阶段。镜头以短暂停留、快速推进和退出构成节奏。暂停会冻结时间、自动镜头、曲线与粒子；手动拖动或方向键仍可旋转。案例、速度、重播、复位和全屏控件由 Vue 管理。路由卸载释放 RAF、事件监听、ResizeObserver 和绘图缓存。

所有决策、价格、延迟和阈值均为模拟展示；没有调用真实模型、执行动作或外发消息。几何布局为程序化复刻，并非原片每一个节点的精确坐标。

## 验证

浏览器回归覆盖 12 案例、五阶段、PASS/HOLD 分支、真实深度与暂停旋转视差、播放控制、深链接刷新、反复挂载清理及移动端。原有 Prompt Crawler 的回归也继续运行。

在本机 Chrome、1080 × 1350、DPR 1 下，3.2 秒运行抽样约 60 FPS；暂停期间模拟时间和绘制帧数均不增加。此结果是本机短时测量，不是所有设备的性能保证。
